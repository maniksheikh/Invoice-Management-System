# Invoice Management System

This is a full-stack invoice management application designed to help users create, manage, and track their invoices efficiently. The project is built with a modern JavaScript stack, featuring a reactive frontend and a robust backend.

## https://invoice-management-system.dev-maniksheikh.workers.dev/

## ✨ Features

- **User Authentication**: Secure user registration and login.
- **Invoice Management**: Create, view, edit, and delete invoices.
- **Dashboard**: An overview of all invoices with their statuses.
- **Responsive UI**: A clean and user-friendly interface that works on all devices.

## 🛠️ Technology Stack

- **Frontend**: 
  - [Nuxt.js](https://nuxtjs.org/)
  - [Vue.js](https://vuejs.org/)
  - [Axios](https://axios-http.com/) for API communication

- **Backend**:
  - [Node.js](https://nodejs.org/)
  - [Express.js](https://expressjs.com/) for the REST API
  - [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/) as the database

# AI Invoice Management System

A full-stack application for managing invoices using AI.

## Project Structure

- `backend/`: Node.js/Express server.
- `frontend/`: Nuxt 3 application with Tailwind CSS.

## Getting Started

### Backend
1. `cd backend`
2. `yarn install`
3. `yarn start` (or `node index.js`)

### Frontend
1. `cd frontend`
2. `yarn install`
3. `yarn dev`

## Tech Stack
- **Frontend**: Nuxt 3, Vue 3, Tailwind CSS.
- **Backend**: Node.js, Express, dotenv, cors.
